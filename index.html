About

About the numbers

Built-in foods use typical USDA values per 100 g. Scanned products come from Open Food Facts, a free community database, so double-check anything that looks off. Label reads copy the printed Nutrition Facts. Claude lookups, screenshot imports and filled-in micronutrients are estimates. Net carbs = total carbs − fiber. Daily Values follow FDA labeling for adults.

Widget

Home and lock screen widget

Shows calories and protein left, your phase and trend, and this app's Anthropic spend. It runs in the free Scriptable app and reads today's numbers from a private GitHub Gist that this app updates after every change.

Set it up

  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token. Under Account permissions set Gists to Read and write. Nothing else. Copy the token.
  2. Paste it above and tap Connect widget, then tap Copy next to the Gist ID.
  3. Install Scriptable from the App Store. Tap +, paste the widget script, and name it Mona's Macros.
  4. Long-press your home or lock screen → Edit / Customize → add a Scriptable widget in any size. Tap it to edit: Script = Mona's Macros, Parameter = your Gist ID.

The gist is unlisted and holds only today's totals, your phase and spend. Your token stays on this phone and can only touch gists.
